# Open-source-Inexpensive-Tethered-Drone-Real-Time-Tether-Tension-Control-System
The CONTROL_DEMO1.zip archive contains the embedded control code developed with STM32CubeMX and implemented in Keil uVision5. This code was used for the control implementation of both the first-generation and second-generation systems.

The remaining six branches contain the complete set of mechanical model files for the first-, second-, and third-generation systems. Each branch provides both SolidWorks files compatible with SolidWorks 2023 or later and STEP files in a universal 3D model exchange format, allowing the models to be opened, reviewed, and modified across different CAD platforms.
