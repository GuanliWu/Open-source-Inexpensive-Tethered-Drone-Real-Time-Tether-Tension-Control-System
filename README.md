# Open-source-Inexpensive-Tethered-Drone-Real-Time-Tether-Tension-Control-System
The CONTROL_DEMO1.zip archive contains the embedded control code developed with STM32CubeMX and implemented in Keil uVision5. This code was used for the control implementation of both the first-generation and second-generation systems.

The remaining six branches contain the complete mechanical model files for the first-, second-, and third-generation systems. Among these branches, three branches provide the SolidWorks source files, which are compatible with SolidWorks 2023 or later, and the other three branches provide the corresponding STEP files in a universal 3D model exchange format. Each pair of branches corresponds to one system generation, allowing the mechanical models of the first-, second-, and third-generation prototypes to be opened, reviewed, and modified in either SolidWorks or other CAD platforms.
